# Testing

Unit vs Integration vs End-to-end

Integration tests may use in-memory database

## AAA

- Arrange - arrange mocks etc.

- Act - call methods 

- Assert - assert if true 

## TDD

Test-driven development - methodology, tests are written before implementation. 

step 1 - write red (failling) under requirements.

step 2 - implementation - until all tests are green (pass)

step 3 - refactoring 

+ code quality, reliability, safer refactoring, documentation etc.

## Mocks

Mocking functionality of other modules for unit testing.

Inheritance, re-implementation of modules.
